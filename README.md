El proyecto consiste en consumir una API de rick y morty, usando react y en este caso router doom y MUI.
Encuentra 3 secciones pricipales: Inicio, Filtrar y personajes, las cards cuentan con detalles por personajes.
Ademas hay paginas de error por si no se encuntra la page o el character.
Este proyecto esta desplegado con netfly y subido a un repositorio de github.
Elaborado para la materia de programacion Web Por Alejandro Noreña Romero.
